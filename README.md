# Location WhatsApp Notifier

A desktop companion app built with Python and PyQt5. It tracks your live GPS location via QtPositioning and automatically fires a WhatsApp alert when you enter specific coordinate destinations.

## Features
* Real-time GPS location tracking.
* Set single-use ("Once") or recurring reminders (specific days of the week).
* Background service running in the System Tray.
* Local database storage using MySQL.
